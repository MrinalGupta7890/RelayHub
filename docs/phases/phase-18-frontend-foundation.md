# Phase 18: Frontend Foundation

## Overview
This phase sets up the React-based frontend dashboard using Vite, TailwindCSS, and TanStack Query.

## Components Implemented
- Vite + React + TypeScript scaffolding
- TailwindCSS design tokens (dark mode, layout shell)
- Authentication pages (Login, Register)
- API Client wrapping `fetch` with token rotation
- Zustand for lightweight client state
